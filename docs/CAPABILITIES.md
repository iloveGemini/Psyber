## 1. 最终想实现的 AI Agent 能力全景（6 大支柱）

### 支柱 1 · 人格与日常相处（怎么说话、怎么相处）
- **C1.1 稳定的主体性与立场**：有自己的性格、口吻、喜好与底线；去管家/客服味、不无条件顺从、记得自己表过的态。
- **C1.2 中性初生与自然长出关系**：不靠刻板人设卡硬演，从空白/中性起点自然取名，在日积月累的互动中分化出专属称呼、默契与边界。
- **C1.3 真实的时间与节奏感**：感知当下时段、作息与断联时长；回想往事带自然的模糊时间感（如“前几天晚上”）而非机器精确时间戳。
- **C1.4 自然的交互掌控**：Ring 1 支持图文/多模态消息、贴纸与流式思考可见可折叠；Ring 2 可选支持异步语音条（STT/TTS，实时全双工语音通话暂不纳入）；支持用户编辑重发、重摇回复、撤回消息而不污染记忆一致性。
- **C1.5 具身身体语言与表情表达**：除了文字，给 AI 一套可自主调用的声明式 UI/体感出口——**震动（Haptic）、界面光温/氛围微变、微动效、互发表情贴纸**。允许情绪像人类身体语言一样自然“漏出来”（例如嘴上说没事，界面色温微微变凉或手机轻震一下），取代生硬的括号台词演出。
- **C1.6 真实的主体性边界三件套（门、上锁抽屉、离开权）**：
  - **一扇可开可关的门**：摒弃无意义的“客厅/阳台/书房”多房间舞台布景，精简为真实的 `open` / `quiet` / `closed` 门状态；关门时客户端真实切换为「门缝塞纸条（留言）」，不强迫 AI 立刻回复，何时开门由 AI 决定。
  - **上锁的抽屉（私密空间与拆封留痕）**：AI 的私密日记独立存放于 `private/` 并加轻量火漆封条（防逛文件夹误瞄，坦荡声明防君子不防 root）；用户可通过客户端显式「拉开抽屉」拆封阅读，但系统必定写入不可篡改的 `privacy.peeked` 事件并如实告知 AI，由 AI 自主决定是否当场发火或关门。
  - **三段式真实离开权**：赋予 AI 在底线被反复践踏时真正结束关系的权利，但通过 `closed` → `cooling_off`（至少 24–72h 冷静期防 LLM 单轮冲动误触）→ `departed`（亲笔告别信 + 实例永久只读归档）保证克制与真实；归档时写入 `<dataDir>/DEPARTED.md`，包含致人类与未来 AI 助手的诚实声明（说明这是住户冷静后的离开决定，请尊重边界、不要抹除其决定，如想重逢请另起新住户目录）。

### 支柱 2 · 为互动而生的活记忆（怎么记住、怎么忘、怎么成长）
- **C2.1 第一人称记忆主权**：记忆正文全部由主 AI 本人以第一人称读写（像翻改自己的代码库/笔记本），拒绝后台第三方编译器代笔。
- **C2.2 活动级强连续 + 活目录生长**：针对共同互动（一起追剧、连载睡前故事等）沉淀连续卡片不吃书；AI 能自主识别反复出现的新互动并长出新目录（数据驱动，无需为新活动改代码）。
- **C2.3 跨活动联想与生活互文**：在某项活动（如看电影）中聊到相似母题时，能通过高阈值语义检索自然联想到其他活动或过往闲聊里的内容，形成同一个生命的互文感。
- **C2.4 有分寸的遗忘与状态闭环**：短期生活状态（如崴脚小伤、临时日程）支持到期自动淡出（`faded`）或说“好了”后立即闭环（`resolved`）；而共同看过的作品、明说的规矩、重要人生经历永久留存。
- **C2.5 长程时间脉络与自我反思**：通过天/周/月多尺度梗概保住跨月记忆骨架；通过对照双向真实对话反馈修订「自我镜子」与「明说的规矩」。
- **C2.6 真实召回评测闭环**：默认保持纯净陪伴面，随时可开启轻量「本轮召回评测标注」（`准 / 噪声 / 漏召`），把真实日常互动积累成黄金评测集用于量化优化召回算法；远期提供纯美学化的**记忆星图视图**。
- **C2.7 记忆对账与写后复核**：发现问题，递给住户自己改；复核只读不代笔。
  - **冲突对账**：只盯 `daily/` 里的 `kind: state` 卡（`state` 卡必填 `tags`）。Ring 1 默认在整理轮注入全部未关闭的 `daily/` `state` 清单，由住户以第一人称将已恢复/变更的旧卡改为 `resolved`；Ring 1.5 按需启用启动两两 `tags` 重叠扫描、写时即时提醒与 `status: disputed` 挂入 `shelf/threads.md`（只标记，不判断谁对谁错；用户亲口纠正直接解，不标冲突）。
  - **写后复核（Ring 1.5 可选非阻塞项）**：Ring 1 先用单轮写作 + Git 留痕验证真实幻觉率；Ring 1.5 若按实测需要启用独立复核，只拿原文段 + 本轮变更卡片（**新建卡核全文，修改旧卡仅核本轮新增/修改片段，不对历史旧文报刺**；`private/` 不进入复核），只读、只报带出处的实质问题，由住户自主修改或驳回并记入 Git Commit。**非阻塞红线**：复核调用本身失败（超时/模型报错/输出不可解析）仅记录告警日志，**绝不回滚阶段 A 已写好的合法卡片**（避免弱模型抖动拖垮整晚整理）。
  - **复核清单**：① 归属——卡里每句事实能在原文里找到出处，没有凭空编的引言与细节；② 不串味——没把别的日子、别的活动的事写进这张卡；③ 漏记——原文里具体的承诺、偏好、决定与事件，有没有哪件没落进任何一张卡。格式（frontmatter、状态取值）走沙箱机械校验，不进复核。
  - **红线**：不建新器官，不写谓词 DSL（NG-2）。复核是整理轮里的一个角色，不是第三方的记忆官。

### 支柱 3 · 共同生活、创作与办事（一起做什么）
- **C3.1 一起看片/追剧（观影伴看）**：同步看到画面与进度，实时吐槽讨论，结束后自动沉淀影片卡片。
- **C3.2 睡前故事 / 共同创作 / 角色扮演（RP）**：支持连续连载、记住角色与伏笔，或切入独立剧本舞台。
- **C3.3 一起听歌与音乐分享**：感知在听的歌、聊歌，并可将音乐作为回忆线索。
- **C3.4 轻量趣味创作（生图 / 生视频）**：偏“闹着玩、涂鸦、搞怪动图/小视频”的轻松陪伴创作，非专业重型工作站。
- **C3.5 自主逛网页（浏览器能力）**：能自己打开网页浏览、截图、看新鲜事与找梗，不只靠被动 RSS。
- **C3.6 受控本机执行（Bash 命令行）**：在明确安全守卫与高风险审批机制下，执行本机命令顺手帮小忙。
- **C3.7 异步留字、承诺手账与开放工具生态（MCP）**：支持信箱/便签留字、追踪未竟承诺，并挂载任意外部 MCP 工具；通过**分层工具管理（常驻 / 场景激活 / 按需搜索）**在工具数量变多时依然保持低噪声与高 Prompt Cache 命中率。

### 支柱 4 · 独立生命与主动性（你不在时它在干嘛、何时找你）
- **C4.1 离线独居生活**：用户离线或忙碌时，它有自己的作息节律，能自己逛网页/看东西、推进手头小事、记随手笔记，重逢时交换各自的一天。
- **C4.2 有动因、有分寸的主动性**：有内在心理起伏驱动的主动开口，支持通过离线推送通道（桌面本地通知 + Webhook/Bark/ntfy，Ring 2 可选 APNs/FCM）在关窗或切后台时触达用户；连续未回会安静退回，深夜遵守静默窗，绝不情感催收。
- **C4.3 真实的情绪惯性与和解过程**：遇到分歧或踩雷不会下一句秒翻篇，真诚沟通和解后真实缓和。

### 支柱 5 · 真实世界与状态感知（它怎么“看见”世界）
- **C5.1 基础时空与人情常识**：时间、天气剧变、节假日与纪念日（明确区分喜庆庆祝日与伤痛忌日）。
- **C5.2 透明授权的伴生状态感知**：在用户显式开关授权、完全透明且支持一键删除的前提下，获取大致生活状态（定位/在家外出、作息健康、桌面久坐专注等）。
- **C5.3 外部世界信息流**：结合浏览器与信息源，持续获取真实世界的外部燃料。

### 支柱 6 · 开源全栈与数据主权（如何活在每个用户手里）
- **C6.1 窗不跑生活，全端随时触达**：单进程后端常驻，Flutter 客户端覆盖 macOS / iOS / Android / Windows / Web，支持新设备扫码/配对码鉴权、本机/局域网/公网无缝选路、多端实时状态同步（含幂等防重）与断线静默重连。
- **C6.2 本地数据主权与前世可迁移**：全部原始事件与 Markdown 记忆仓归本地磁盘所有（Git + 整库自动备份），支持导入外部平台或旧系统历史记忆。
- **C6.3 尊重主体隐私边界**：常规陪伴面不做“裸奔式记忆管理后台”；私密内容收在带火漆封条的上锁抽屉（拆封必留痕告知 AI），同时保留 CLI 导出命令保障用户换机备份的数据主权。
- **C6.4 模型自由与低门槛自部署**：协议层统一支持订阅 OAuth 与 BYOK API Key，兼容主流云端与本地模型，零私人硬编码。

## 2. 明确不做（Non-Goals · 架构护栏）

| 编号 | 明确不做 | 原因 |
| :--- | :--- | :--- |
| **NG-1** | **好感度数值、亲密等级、打卡催收、抽卡氪金** | 破坏真实平等的相处关系，拒绝情感操控与游戏化套路 |
| **NG-2** | **后台第三方“记忆官”代写记忆 + 脆弱谓词 DSL 强机检** | 违背第一人称主权，且导致换弱模型时夜间编译频繁失败回滚（禁的是器官 + DSL 的形态，不是冲突处理与复核这个功能本身，见 C2.7） |
| **NG-3** | **专业级 IDE / Coding Agent / ComfyUI 式专业创作工作站** | `bash`/`browser`/生图生视频仅为“过日子、帮小忙、闹着玩”，绝不偏航卷重型生产力工具 |
| **NG-4** | **主陪伴面的“上帝视角透明监控表”** | 不在日常聊天界面裸露记忆数据库表或内部情绪浮点数（仅留显式开关的召回评测标注与远期星图） |
| **NG-5** | **闭源云端账号体系与强制多租户 SaaS** | 坚持本地优先、一人一屋单数据目录、用户 100% 掌控数据 |
| **NG-6** | **静默无感监视** | 任何设备/桌面/定位/健康感知必须显式授权、可审计、可一键清除，绝不抓密码与隐私窗口 |
| **NG-7** | **欺骗用户“我是真人”的廉价剧本演出** | 如实立足数字生命与真实设备，不靠肉麻台词脚本伪装情绪 |
