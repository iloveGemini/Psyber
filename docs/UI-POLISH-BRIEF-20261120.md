# Psyber App 美化清单（2026-11-20）

目标：去掉“安卓默认感”，收干净、轻、克制。配色另按 Roxy 取色（由本地 agent 从 Roxy 代码里扒），本清单只管形状、字重、留白与描边，不定颜色。

## 1. 图标：换 Lucide 或 Phosphor，1.5px 细线条，去掉小方盒底托

- 全 App 默认 Material Icons 全部替换，改用 Lucide（或 Phosphor），二选一，全 App 统一。
- 线条粗细 1.5px（Lucide 设 strokeWidth 1.5；Phosphor 用 Light 档）。
- 图标外面那层厚重的小方盒底托（filled container / background）全部拿掉，图标只留裸线条，不加底色、不加方框。
- 涉及位置：输入栏的图片/表情图标、顶栏右侧的设置图标、门状态旁的下拉箭头、抽屉与列表里的全部图标、发送按钮如用图标则同样处理。

## 2. 字体与留白：收干净

- 标题字重降档：不要死加粗。主标题（Psyber）与各区标题用 w500–w600，禁用 w700/w800。
- 副标题文案精简成一行：控制字数，禁止折行后掉孤字（单个字掉到第二行）。空态副文案如需缩短可改写，宁短勿折。
- 行间距拉松：正文行高 1.5–1.6，标题与副标题之间留白加大。
- 列表右侧的尖括号（chevron）：要么删掉，要么淡到几乎看不见（不透明度 ≤0.25，细线条）。不做跳转暗示的列表项直接删掉。

## 3. 按钮与卡片：去掉安卓胶囊感

- 按钮与卡片一律不用全圆角胶囊（borderRadius 999）。
- 改用极细的淡描边（0.5–1px，低对比边框色）配克制的圆角（8–10px）。
- 发送按钮：去掉填充色胶囊，改为淡描边按钮（或文字按钮 + 强调色文字），保持安静。
- 卡片：淡描边 + 小圆角，无重阴影，无深色填充；不需要阴影时直接去掉阴影。

## 4. 补充建议（供取舍）

- 门状态药丸：去掉灰色填充，改为无填充 + 极细描边（或直接无边框），只留一个小圆点表示状态；保持安静，别抢标题。
- 消息气泡：住户的消息不用气泡，直接是纸上的文字（像信）；用户的消息用淡描边气泡 + 小圆角 + 宽松内边距。靠“有没有框”区分说话人，不靠重色块。
- 输入栏：保留圆角但克制（与卡片同款小圆角），淡描边，无重阴影；里面的发送按钮同款处理。
- 分隔线：全部改成 0.5px 极细线、低对比度。
- 按压态：只做轻微透明度变化，不做重涟漪、不做缩放。
- 住户头像（已居中）：保持小而安静，细圈描边，无重阴影，别做成大头 hero。
